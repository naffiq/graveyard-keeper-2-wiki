Milestones

Milestones are a fast travel mechanic that allows the Keeper to travel to different locations. Travel is only possible between Milestones.

Each milestone must be activated using Faith, after which it can be used indefinitely with no cooldown.

Activating a milestone contributes to the Milestone Hunter Inspiration.
