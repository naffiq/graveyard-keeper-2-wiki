Alchemy

Alchemy is a game system in Graveyard Keeper 2. The Keeper can create alchemical recipes using flask and a combination of runes. Flask need to be placed in the flask shelf, while Runes are found on items and must be revealed by studying them.

Recipes

Alchemy recipes are created in a Laboratory. The result is determined solely by the Runes of the items placed in the Laboratory. Their Runes are combined, and the resulting recipe depends on the total number of each Rune rather than the specific items used. This allows the same recipe to be created using different combinations of items, as long as they provide the same total number of Runes.
