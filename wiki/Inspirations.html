Inspirations

Inspirations is a game system in Graveyard Keeper 2. Inspirations are divided into five types, corresponding to the same categories as Masteries. Each type has its own talent tree, where inspiration points can be spent to unlock perks.

Inspiration points are earned by filling an inspiration bar. Each task adds one square of progress, and higher inspiration levels require more squares to fill the bar. Some tasks have multiple levels, with the first level usually being free, while subsequent levels require Faith.

Tasks cover a wide range of gameplay activities and are related to the area associated with each type of Inspiration.

Talent tree

Each node in the talent tree costs 1 Inspiration Point and can only be unlocked if the preceding nodes have already been purchased.
